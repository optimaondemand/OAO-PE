# Canvas Embeds — Mission: Move! 5th Grade PE

Paste one snippet into the matching Canvas page's **HTML editor** (the `<>` button in the Rich
Content Editor), then Save. Each lesson is hosted on GitHub Pages and loads inside the page.

**Height 840** is a contained "module" viewport — the sticky progress rail, scroll-reveal, and the
Mission-Complete payoff all rely on the embed scrolling internally. It's the one number you can tune.
